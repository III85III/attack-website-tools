# Qolam Sentinel 0.11.1

- صفحهٔ اسکن به یک ورودی URL و یک دکمهٔ واحد تبدیل شد؛ پروفایل‌ها، گزینه‌های اضافی و پنل رویدادها حذف شدند.
- اجرای اسکن همیشه از ارزیابی عمیق داخلی شروع می‌شود؛ اگر ZAP محلی فعال باشد، اسکن فعال ZAP هم با تأیید صریح کاربر و محدودهٔ همان origin اجرا می‌شود.
- وضعیت کوتاه اجرا و یافته‌ها در همان صفحه می‌مانند.
