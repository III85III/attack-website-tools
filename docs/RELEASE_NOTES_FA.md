# Qolam Sentinel 0.10.0 — یادداشت نسخه

## قابلیت‌های تازهٔ ارزیابی عمیق وب

- دو حالت مجزا دارد: ارزیابی پایه و ارزیابی عمیق کم‌خطر.
- حداکثر ۲۵ صفحهٔ هم‌مبدأ را می‌خزد و نام پارامترهای query را پیدا می‌کند.
- سیاست CORS را با یک Origin آزمایشی بررسی می‌کند.
- حداکثر ۱۰ پارامتر query را با marker بی‌خطر و یک ورودی single-quote آزمایش می‌کند.
- مقدارهای query در شواهد گزارش ذخیره نمی‌شوند؛ پاسخ فقط تا سقف ۱ مگابایت خوانده می‌شود.
- همهٔ این تست‌ها GET هستند؛ redirect دنبال نمی‌شود، فرم ارسال نمی‌شود، credential استفاده نمی‌شود و payload تغییردهندهٔ داده وجود ندارد.

## محدودیت‌های پوشش

بازتاب marker و پیام دیتابیس کاندیدای بررسی‌اند، نه اثبات exploit. این نسخه بخش‌های نیازمند ورود، فرم‌های POST، APIهای JSON، XSS ذخیره‌شده/DOM، کنترل دسترسی و منطق کسب‌وکار را پوشش نمی‌دهد. این ابزار نمی‌تواند تضمین کند همهٔ آسیب‌پذیری‌ها را پیدا می‌کند و جای تست نفوذ حرفه‌ای با مجوز و اعتبارنامهٔ آزمایشی را نمی‌گیرد.

## انتشار

این نسخه تحت GPL-3.0-only منتشرشدنی است؛ متن مجوز و اعلان وابستگی‌ها داخل بسته قرار دارد. ممیزی کامل وابستگی‌های غیرمستقیم و DLLهای بومی و امضای کد هنوز انجام نشده است.
