# Qolam Sentinel 0.11.0 — یادداشت نسخه

## اتصال واقعی OWASP ZAP

- پروفایل جدید OWASP ZAP اجرای daemon محلی را بررسی می‌کند و دیگر صرفاً هشدارهای قبلی را نمی‌خواند.
- برای هر اجرا، context موقت با regex محدود به origin واردشده می‌سازد؛ همان context برای خزیدن و اسکن فعال استفاده می‌شود.
- پیشرفت خزیدن و اسکن نمایش داده می‌شود؛ زمان اجرا حداکثر ۱۰ دقیقه است و در timeout توقف اسکن درخواست می‌شود.
- پس از پایان، هشدارهای ZAP به‌یافته‌های Sentinel تبدیل می‌شوند و context موقت حذف می‌شود.
- تأیید مجوز به‌همراه پنجرهٔ هشدار اثر احتمالی اسکن فعال لازم است.

## پیش‌نیاز و محدودیت

OWASP ZAP جداگانه نصب می‌شود و باید API محلی آن روی `127.0.0.1:8080` فعال باشد. این پروفایل اسکن فعال ZAP را اجرا می‌کند؛ درخواست‌های آزمایشی ممکن است بر سرویس اثر بگذارند. فقط روی سامانه‌ای اجرا شود که مجوز روشن برای آن وجود دارد. یافته‌های scanner-reported نیاز به بررسی انسانی دارند.
