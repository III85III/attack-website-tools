# Security policy

The currently maintained release candidate is **0.19.0**. Releases are unsigned; verify the published SHA-256 checksums.

## Report a vulnerability in Sentinel

Use [GitHub private vulnerability reporting](https://github.com/III85III/attack-website-tools/security/advisories/new).
Include the affected version, a minimal reproduction, impact and sanitized evidence.
Do not post credentials, customer data, private target reports or live session tokens publicly.

Reports about third-party websites belong to the target owner's authorized disclosure process.
Sentinel's responsible-use notice does not grant target authorization.

See the [Security Model](docs/SECURITY_MODEL.md) for limits and evidence handling.
A completed scan or zero findings is not proof of security.
